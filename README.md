# Pricing Panel

A pricing table page built with HTML, CSS and Sass.

## About The Project

A static "Price Tiers" page presenting three pricing plans (Personal, Small team, Enterprise), each with an icon, a feature list, a price and a sign-up button. Styles are written in Sass (`app.scss`) and compiled to `app.css`.

## Built With

- HTML / CSS
- Sass

## Getting Started

Open `index.html` in a browser.
